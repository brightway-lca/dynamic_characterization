## [Unreleased]

### Added
* New parameter set `"ar6"` for the default characterization functions, selected with the new argument `characterization_options={"parameter_set": "ar6"}` of `characterize` and `create_characterization_functions_from_method`. It reproduces the IPCC AR6 emission metrics (WG1 Ch. 7, Tables 7.15 and 7.SM.7): climate-carbon feedback for non-CO2 gases (Gasser et al. 2017; mean, upper and lower parameter sets), fossil and non-fossil CH4 with the CO2 from oxidation, N2O with its ozone and CH4 effects, the CFC-11/12 adjustment, the SF6 lifetime of Table 7.15, AR6 radiative efficiencies of CO2, CH4 and N2O, and annual forcing that adds up to AGWP(H). GWP100 then matches the static IPCC 2021 factors, e.g. fossil CH4 29.8 (legacy 26.7), N2O 273 (263.6), CF4 7380 (7058). Further options: `climate_carbon_feedback`, `ccf_parameters`, `biogenic_oxidation_co2`, `ch4_oxidation_yield`, `unspecified_origin`, `flow_overrides`. Not yet available for the prospective metrics.
* Indirect gases in the `"ar6"` parameter set, from published parameter sets (`ipcc_ar6/data/precursor_parameters.json`): CO (default Fry et al. 2012 multi-model mean, GWP100 1.63, plus 1.57 oxidation CO2 if fossil), VOC (Fry et al. 2012, 4.50 per kg VOC), H2 (Warwick et al. 2023, 11.4; or Sand et al. 2023), and opt-in NO/NO2/"Nitrogen oxides" (Fry et al. 2012) with optional nitrate aerosol. New options `include_precursors`, `precursor_parameter_sets`, `include_nox`, `nox_nitrate`, `precursor_ccf`.
* The `"ar6"` parameter set works with the prospective metrics (`pGWP`, `pGTP`, `prospective_radiative_forcing`): CO2 and all CO2 terms of other gases (oxidation, uptake, climate-carbon feedback) follow the scenario CO2 radiative efficiency and impulse response, CH4 and N2O use the scenario radiative efficiencies with the AR6 adjustments and indirect effects, and the CO2 reference is computed in the same way. New module `ar6_prospective`; `ar6_core` accepts a tabulated CO2 response (`TabulatedCO2Response`). Horizons up to 100 years; `time_varying_re` is not supported with `"ar6"`.
* `compare_with_static(method, time_horizon, characterization_options)`: table of static factor vs dynamic GWP per flow.
* New modules `ipcc_ar6.ar6_core`, `ipcc_ar6.gases`, `options`, `ar6_dispatch`; data file `ipcc_ar6/data/ar6_parameters.json` (generated by `dev/build_ar6_data.py`).

### Deprecated
* Using the default characterization functions without `characterization_options` issues a one-time `FutureWarning`: the default parameter set will change from `"legacy"` to `"ar6"` in version 2.0. Pass `{"parameter_set": "legacy"}` to keep the current functions without the warning.

### Fixed
* CAS numbers are now normalised before the default characterization functions are matched to the halocarbon data (`decay_multipliers.json`). Zero padding (`000075-38-7` vs `75-38-7`) and stray whitespace in the data keys (`"000375-17-7 "`, `"0 5595-10-8"`) no longer prevent a match. In ecoinvent 3.12 this adds "Vinylidene fluoride" and "Methyl vinyl ketone", which were previously left uncharacterized. HFO-1234ze(E), listed in the data with a CAS typo (`29188-24-9`), is also found under its correct CAS `29118-24-9`. New helpers: `dynamic_characterization.flows.normalize_cas`, `is_valid_cas`, `build_cas_index`.
* Fixed `pGTP` for GHGs outside the Watanabe module (CO and the halocarbons characterized with `fallback_to_ipcc=True`). The integrated radiative forcing was used as if it were an AGTP, and the emitted amount was applied twice, so results were far too large and grew with the square of the amount (e.g. CF4 pGTP100 ≈ 150 000 per kg instead of the order of the AR6 GTP100 of 9 744). The AGTP is now computed from the function's radiative forcing with the temperature response of the prospective module, consistent with the CO2 reference. A characterization function can provide its own `agtp(time_horizon)`, which is then used instead.

### Documentation
* Corrected the docstrings of `create_characterization_functions_from_method`, `characterize_ch4` and `characterize_co`: the default functions include no climate-carbon feedback for non-CO2 gases (the docstring claimed it for CH4 and N2O), "Methane, non-fossil" is characterized (with the same function as fossil methane), CO is characterized by its oxidation to CO2 only, and the forcing is integrated to `time_horizon - 1` years.

## [1.4.3] - (2026-08-21)
* Fixed prospective RF being constrained to after 2030 even if earlier data exists

## [1.4.2] - (2026-08-14)
* The error raised when a prospective metric is calculated without a scenario now explains what to do: full import path, a copy-pasteable `set_scenario` call, and the available IAM-SSP-RCP combinations.
* Fixed `TypeError: ... got an unexpected keyword argument 'time_varying_re'` for the `pGWP` and `pGTP` metrics: `time_varying_re` was passed to every characterization function, including the IPCC AR6 fallback functions (CO and the GHGs from `decay_multipliers.json`), which don't accept it.

## [1.4.1] - (2026-08-03)
* Fixed a regression introduced in 1.4.0 where ordinary CO2 emission flows (e.g. `Carbon dioxide, fossil` emitted to any air subcategory) got no default characterization function and were silently skipped, understating dynamic climate scores by roughly an order of magnitude. `characterize_uptake=False` now only suppresses the uptake functions instead of all CO2 characterization.
